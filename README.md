# Fentanyl Ce Simulator V1.0.0

> ## ⚠ 研究・教育目的専用 — 臨床使用を禁止します
>
> **本ソフトウェアを実際の患者の投与量決定・診断・治療方針の根拠として使用してはなりません。**
>
> - 医療機器ではありません。いかなる規制当局の承認・認証・届出も受けていません。
> - 表示される濃度は母集団薬物動態モデルによる**理論値**であり、患者の実測濃度ではありません。
> - 鎮痛指標は公表された母集団統計に基づく参考値であり、個々の患者の鎮痛充足度を示しません。
> - 実装した 3 つの PK モデルは、**同一投与量に対して最大 1.8 倍異なる Ce** を与えます
>   ([モデル間の差は小さくない](#モデル間の差は小さくない))。単一の数値を正解として扱えません。
> - 前向き検証を行っていません。実測濃度との対比、臨床アウトカムとの対比のいずれも未実施です。
>
> 想定する用途は、薬物動態モデルの挙動を学ぶこと、モデル間の不一致を可視化すること、
> および研究上のシミュレーションに限られます。

フェンタニルの効果部位濃度 (Ce) を予測しながら、その濃度が鎮痛としてどの位置にあるかを
文献値に紐づけて表示する研究・教育用シミュレータです。UI は同シリーズの
Propofol TCI TIVA アプリに合わせた 3 ステップ構成です。

- **Step 1 リアルタイム** — ボーラス / 持続投与に対する Cp・Ce を実時間で予測し、鎮痛指標を同時表示
- **Step 2 鎮痛評価** — 任意の Ce における鎮痛指標、Ce–効果曲線、その Ce を保つ投与量
- **Step 3 投与記録** — 麻酔記録の投与イベントから全経過を再構成し、投与中止後の減衰時間と、
  記録した鎮痛評価からその患者自身の MEAC を推定

ブラウザで `index.html` を開くだけで動作します。ビルド不要、外部依存は Chart.js のみ。

## 実装した PK モデルと、その選択理由

### 結論を先に

**ke0 = 0.147 /min は Scott & Stanski 1987 の PK と同時推定された値であり、
他の PK モデルに流用するとボーラス後のピーク時刻がずれます。**
そのため本アプリの既定は「Shafer PK + Scott/Stanski ke0」ではなく
**Scott & Stanski 1987 の PK/PD 一式**としました。

検証: フェンタニルのボーラス後の挙動として文献に引用される
「Ce は 3.6 分でピークに達し、その値は初期血漿濃度の 17%」を再現できるのは
Scott & Stanski の組み合わせだけです。

| モデル | Ce ピーク時刻 | ピーク Ce / Cp(0) | 文献値との一致 |
|---|---|---|---|
| 文献値 (Shafer & Varvel 1991 経由) | 3.6 分 | 17% | — |
| **Scott & Stanski 1987 PK + 自身の ke0** | **3.71 分** | **16.5%** | **一致** |
| Shafer 1990 PK + 流用 ke0 | 3.17 分 | 13.7% | ずれる |
| Bae 2020 PK + 流用 ke0 | 4.25 分 | 20.1% | ずれる |

これは Minto ら (Anesthesiology 2003;99:324-33, PMID 12883405) が
"naive approach" として警告している、ke0 を別の PK モデルへ移植する際の問題そのものです。
3 モデルすべてを実装し切り替え可能にしてありますが、hybrid の 2 つには
UI 上で `HYBRID` バッジを付け、ピーク時刻のずれを常時表示しています。

### ただし、この既定が最適とは限りません

上の根拠は「PK と ke0 の内部整合性」です。**問いによっては別のモデルの方が適切になります。**
これは本アプリを既定モデルだけで使うべきでない理由でもあるので、明示しておきます。

**ke0 の影響は最初の 5 分でほぼ消えます。** ke0 を 0.10 / 0.147 / 0.25 と ±70% 振ったとき
(PK は Bae 固定) の Ce の開きと、ke0 を固定して PK モデルを振ったときの開き:

| 時刻 | ke0 を振った場合 | PK モデルを振った場合 |
|---|---|---|
| 3 分 | 1.94× | 1.79× |
| 10 分 | **1.10×** | 1.80× |
| 30 分 | **1.29×** | 1.53× |
| 120 分 | **1.10×** | 1.28× |

つまり ke0 の整合性は、MEC / MEAC 判定にとって最も効かない時間帯にしか効きません。
MEAC はもともと定常状態 (Ce ≒ Cp) で定義された量なので、なおさらです。
一方 **Bae 2020 は PK と MEAC を同一研究・同一患者・同一アッセイで決めており**、
画面上の濃度と比較対象の閾値が同じ物差しに乗ります。

60 kg・フェンタニル 100 µg + 50 µg (30 分) + 50 µg (70 分)・120 分の症例で、
「Ce が MEAC 0.99 ng/mL を上回っていた時間の割合」:

| モデル | MEAC 超過時間 |
|---|---|
| Scott & Stanski | 12.3% |
| Shafer | 44.2% |
| Bae | 43.8% |

同じ投与記録に対する臨床的な答えが 3.6 倍違い、外れているのは既定の Scott & Stanski です。

**用途別の目安:**

| 見たいもの | 適したモデル | 理由 |
|---|---|---|
| ボーラス後のピーク時刻 | Scott & Stanski | 文献値 3.6 分 / 17% を再現する唯一の組 |
| MEC / MEAC に対する充足 | Bae 2020 | 閾値と濃度が同一研究由来。体重共変量あり |
| 投与終了後の減衰 | **3 モデルすべて** | 幅そのものが不確実性 (下記) |

投与終了後については、効果で滴定した共通の起点 (Ce 1.5 ng/mL) から見るとモデル間の
濃度差は 1.00–1.38× まで縮みますが、下降曲線が平坦なため**時刻の差は 2–3 倍に開きます**
(手術 480 分後に MEAC を下回るまで: Scott & Stanski 152 分 / Shafer 83 分 / Bae 55 分)。
Ce の予測が 10% ずれるだけで到達時刻は 30–92 分動きます。
**減衰時間を分単位の予定として読むことはできません。** 順序と桁として扱ってください。

なお覚醒そのものは、フェンタニル単独の Ce からは予測できません。覚醒を支配するのは
併用する鎮静薬であり、フェンタニルの寄与は相乗作用を介した間接的なものです
(Kazama 1998, PMID 9778007 ではフェンタニル 1 ng/mL がプロポフォール Cp50 を 30–44%
低下させます)。相互作用モデルは本バージョンには実装していません。

### 1. Scott & Stanski 1987（既定）

Scott JC, Stanski DR. *J Pharmacol Exp Ther* 1987;240:159-66. **PMID 3100765**

PK と ke0 を同一データから同時推定した、本アプリで唯一 PK/PD が単一研究に由来するモデル。
パラメータ値はオープンアクセスの総説
Choi BM. *Korean J Anesthesiol* 2016;69:211-8 (PMC4891531) Table 3 に
Scott & Stanski 1987 として掲載されている値を使用:

| | 値 |
|---|---|
| V1 | 13.0 L |
| k10 / k12 / k21 / k13 / k31 | 0.0492 / 0.380 / 0.0960 / 0.179 / 0.0077 /min |
| ke0 | 0.147 /min |
| 導出される V2 / V3 | 51.5 L / 302 L |
| 導出される CL / Q2 / Q3 | 0.640 / 4.94 / 2.33 L/min |

限界: 成人男性のみ、効果指標は EEG spectral edge、体重共変量なし。
同論文は 20 歳から 89 歳で必要量が 50% 減ることを示していますが、
それは**薬力学的な脳感受性の変化**であって PK の変化ではないため、
年齢は Ce 予測には反映されません。

### 2. Shafer 1990 PK + Scott/Stanski ke0（HYBRID）

Shafer SL, Varvel JR, Aziz N, Scott JC. *Anesthesiology* 1990;73:1091-102. **PMID 2248388**

V1 6.09 L, V2 28.1 L, V3 228 L, CL 0.504, Q2 2.87, Q3 1.37 L/min（opentci.org の実装値）。

このパラメータ集合の同定には注意が必要でした。文献検索の過程で
V1 = 26.6 L とする別の値が出てきましたが、以下の 3 点から V1 = 6.09 L が正しいと判断しています:

1. 原著抄録が明示的に「従来の推定より**小さい中心コンパートメント容積**と、
   より速い初期分布半減期」と述べており、Scott & Stanski の V1 13.0 L より小さいはずである
2. V1 = 6.09 L から導かれる微視的速度定数 (k10 0.083, k12 0.471, k21 0.102, k13 0.225, k31 0.0060)
   が TCI 文献で Shafer モデルとして引用される値と 3 桁一致する
3. V1 = 26.6 L では k12 が Scott & Stanski より**遅く**なり、抄録の記述と矛盾する

限界: 血漿 PK のみで ke0 を持たない。
Shibutani ら (*Anesthesiology* 2004;101:603-13, **PMID 15329584**) は
本モデルが体重増加に伴い濃度を系統的に過大評価すると報告しています
(誤差 vs 総体重の R² = 0.689)。40〜90 kg の外ではアプリが警告を出します。

### 3. Bae 2020 allometric PK + Scott/Stanski ke0（HYBRID）

Bae J, Kwon M, Lee YH, Lee EK, Choi BM, Noh GJ. *Br J Anaesth* 2020;125:976-85. **PMID 32861508**

70 kg 標準成人で V1 10.1, V2 26.5, V3 206 L, Cl 0.704, Q1 2.38, Q2 1.49 L/min。
（原著の Q1 / Q2 は本アプリの Q2 / Q3 に対応します。）
3 モデル中で唯一体重を共変量に持ちます。

**未解決の仮定**: 原著抄録は allometric expression を用いたと述べるのみで
exponent を記載しておらず、全文は非公開です。本実装は慣用的な理論値
（容積 1、クリアランス 0.75）を仮定しています。
`js/fentanyl-pk.js` の `BAE_VOLUME_EXPONENT` / `BAE_CLEARANCE_EXPONENT` で
1 箇所修正できるようにしてあります。**全文を入手できたら要確認**です。

### モデル間の差は小さくない

60 kg 患者にフェンタニル 100 µg をボーラスし 50 µg/hr で持続した場合の 6 分後の Ce:

| モデル | Ce (ng/mL) | V1 (60 kg) |
|---|---|---|
| Scott & Stanski | 1.233 | 13.00 L |
| Shafer hybrid | 2.092 | 6.09 L |
| Bae hybrid | 2.246 | 8.66 L |

**約 1.8 倍**の開きがあります。主因は V1 の違い（13.0 L 対 6.09 L / 8.66 L）で、
ボーラス直後の Cp がそのまま Ce に伝わるためです。
Ce の絶対値を鎮痛閾値と比較する用途では、どのモデルを使ったかが結論を変えます。
「比較」モードで 3 モデルを重ねて表示できます。

## 鎮痛効果の表示

Ce をそのまま出すだけでなく、その濃度が鎮痛としてどこに位置するかを表示します。
**すべての数値が特定の論文に紐づいており、出典なしの定数はありません。**

### 濃度帯

| 濃度帯 | Ce (ng/mL) | 出典 |
|---|---|---|
| 鎮痛閾値下 | < 0.63 | Gourlay 1988 (PMID 3354866): MEC 0.63 ± 0.25 |
| MEC 帯 | 0.63 – 0.99 | Gourlay 1988 / Bae 2020 (PMID 32861508) MEC 0.72 |
| 術後鎮痛域 | 0.99 – 1.67 | Bae 2020: MEAC 中央値 0.99 (IQR 0.76-1.28) |
| 術中補助域 | 1.67 – 3.26 | McEwan 1993 (PMID 8489058): 1.67 で MAC 50% 減少 |
| 強侵襲対応域 | 3.26 – 4.17 | Glass 1993 (PMID 8489055): 皮膚切開 Cp50 3.26 / Cp50-BAR 4.17 |
| 高濃度域 | ≥ 4.17 | Mildh 2001 (PMID 11574361): 呼吸数 50% 低下 EC50 3.5 |

### 母集団確率曲線

MEC / MEAC は患者ごとの閾値なので、その閾値の分布を Ce で評価すれば
「その Ce で鎮痛が得られている患者の割合」になります。
Bae 2020 の中央値と四分位値から log-logistic を当てはめました:

    P(Ce) = 1 / (1 + (median/Ce)^γ),  γ = 2·ln(3) / ln(Q3/Q1)

γ は選んだのではなく四分位で決まります。MEAC では γ = 4.215 となり、
曲線は公表された Q1 で 24.7%、中央値で 50.0%、Q3 で 74.7% を返します。
（MEC の IQR は対数空間で非対称なため、単一の log-logistic では両四分位を
同時に通せません。中央値を通し四分位の差を折半する当てはめになっています。）

### 吸入麻酔薬 MAC 減少

McEwan 1993 の公表 3 点（1.67 ng/mL で 50%、3 ng/mL で 63%、10 ng/mL でさらに 19%）に
双曲 Emax を当てはめました。2 点から閉形式で決まる Emax = 93.5%, C50 = 1.454 ng/mL が、
3 点目の 82% を 81.7% として再現します（当てはめに使っていない点での検証）。

### 維持速度は「その Ce に到達する速度」ではない

Step 2 は目標 Ce に対する維持速度を `rate = Ce × CL` から表示しますが、
これは**定常状態の関係**です。フェンタニルは第 3 コンパートメントが大きく
(Scott & Stanski で V3 302 L)、そこへの移行が遅い (k31 = 0.0077 /min) ため、
その速度を一定で流し続けても Ce が目標の 90% に達するのは:

| モデル | 定常の 90% までの時間 |
|---|---|
| Scott & Stanski | 24.3 時間 |
| Shafer | 22.9 時間 |
| Bae (70 kg) | 15.6 時間 |

手術時間内にはまず到達しません。この数値をカードとして併記しているのは、
維持速度を「その Ce になる速度」と読み違えると投与量を過小評価するためです。
実際、100 µg ボーラス + 80 µg/hr を 150 分続けた例では、
Ce が MEAC (0.99 ng/mL) 以上だったのは記録全体の 11% にすぎませんでした。

## 個体化 MEAC 推定（Step 3）

上の濃度帯や母集団確率は、すべて Ce の単調変換です。単調変換は情報量を増やしません。
そこで Step 3 に、**その患者自身の閾値を推定する**機能を置きました。
記録が 1 件でも入れば、表示は Ce だけの関数ではなくなります。

### モデル

患者自身の MEAC を \(m\) とし、\(\ln m\) の空間で扱います。

```
事前分布   ln m ~ Logistic( ln 0.99 , s_between )
尤度       P(鎮痛十分 | Ce = c, m) = 1 / (1 + exp( -(ln c - ln m) / s_within ))
```

2 つの尺度はどちらも公表統計から導出しており、選んだ値ではありません。

| 尺度 | 由来 | 対数スケールの SD |
|---|---|---|
| `s_total` | Bae 2020 の MEAC 四分位から当てはめた γ = 4.215 | 0.430 |
| `s_within` | Gourlay 1988 (PMID 3354866) の**患者内 CV 30.2%** | 0.295 |
| `s_between` | 分散分解 `sd_between² = sd_total² − sd_within²` | 0.313 |

この分解が構成の要です。Bae が観測したばらつきは患者間成分と患者内成分の合計なので、
尤度を事前分布で積分すると**公表された母集団曲線に戻ります**。
つまり記録が 0 件のときの表示は母集団曲線と一致し（検証で最大差 1.03 ポイント）、
記録が増えるほど滑らかに個体化されます。劣化の仕方が安全です。

事後分布は \(\ln m\) 上の 801 点グリッドで、事前密度に各観測の対数尤度を足すだけで求まります。

### 表示するもの

- 推定 MEAC の中央値と 90% 信用区間
- 個体化された P(鎮痛十分 | Ce) 曲線と、母集団曲線の重ね描き、および観測点
- 記録終了時点の Ce における個体化された鎮痛確率
- **同じ記録を 3 つの PK モデルで読んだときの推定 MEAC の並び**

最後の行は副産物ですが有用です。PK モデルの誤差はそのまま閾値推定に吸収されるため、
この広がりは患者ではなくモデルの差を表します。外部データなしにモデル間の不一致を
定量化する入口になります。

### 検証で確かめていること

`validation/validate-individualisation.js` (29 項目):

- 分散分解が算術的に整合し、患者間成分 > 患者内成分になっている
- 記録 0 件の予測分布が公表母集団曲線と一致する（最大差 1.03 ポイント）
- 事後分布が正しい確率密度である（積分 = 1）
- **回復テスト**: 既知の閾値 (0.6 / 1.8 / 3.2 ng/mL) を持つ仮想患者から生成した
  60 件の観測で、事後中央値がそれぞれ 0.61 / 1.87 / 3.52 と真値を 25% 以内で回復し、
  信用区間が真値を含む
- 一貫した記録で区間が単調に狭まる（0 件 1.05 → 20 件 0.54 ng/mL）
- 矛盾した記録でも事後が潰れず、区間が広いまま保たれる
- 「高い Ce で不十分」は推定閾値を上げ、「低い Ce で十分」は下げる

### 率直な限界

1. **事前分布も患者内変動も術後研究由来です。** Bae は開腹術後 PACU、Gourlay は術後 PCA。
   術中の外科的侵襲への適用は出典が支持しない外挿です。術後鎮痛での使用が本来の適用範囲です。
2. **PK モデルの誤差が閾値推定に吸収されます。** 3 モデルで Ce が最大 1.8 倍違う以上、
   推定 MEAC は「そのモデルを通して見た閾値」であり、必ずモデルとセットで解釈してください。
3. **オピオイド単独の閾値には原理的な天井があります。** Bouillon 2004 (PMID 15166553) は
   remifentanil 単独では体動も喉頭鏡への反応も消せず、propofol との相乗効果で効くことを示しました。
   術中の反応予測をフェンタニル Ce だけで行う精度には限界があります。
4. **判定基準の一貫性が前提です。** 「鎮痛不十分」の定義が症例内で揺れると、
   観測ノイズが Gourlay の患者内 CV を超え、推定が偏ります。

### 次の検証（未実施）

既存の麻酔記録に後ろ向きに適用し、「個体化した指標は、その後のレスキュー投与イベントを
母集団曲線より良く予測するか」を prediction probability または log-loss / Brier score で
比較する設計が、指標として成立するかの直接の検定になります。これはまだ行っていません。

### 実装しなかったもの

一次文献を確認できなかったため、以下は意図的に表示していません:

- **気管挿管に対するフェンタニル単独の Ce50** — 該当する一次研究が見つかりませんでした。
  よく引用される Kazama 1997 (PMID 9286884) は fentanyl 併用下の **propofol** の Cp50 であり、
  フェンタニル自身の Ce50 ではありません

  最も近い確認済みの値は Cartwright 1983 (PMID 6414339) の
  「1.5–3.0 ng/mL で CO2 応答曲線が**すでに 50% 抑制**」で、これは別の主張です。

## 検証

```
npm test        # PK 44 + 鎮痛 26 + 個体化 29 = 99 checks
```

PK 側で確認していること:

- 3 モデルの微視的速度定数が出典の値を再現する
- Scott & Stanski のみが公表 tpeak 3.6 分 / ピーク比 17% を再現する
- 消失を切ると総薬物量が保存される（質量保存）
- 定常状態で Cp → rate/CL、Ce → Cp に収束する
- 積分刻みを 8 分の 1 にしても Ce が 1e-4 ng/mL 以上動かない
- ボーラスの線形性と重ね合わせ、Ce が Cp に遅れること、投与中止後の単調減衰
- context-sensitive decrement time が投与時間とともに延びること
- 30〜200 kg で Bae モデルが有限かつ正のパラメータを返すこと
- 定常到達時間が投与速度に依存しないこと（線形系であることの確認）

鎮痛側で確認していること:

- 3 本の曲線がすべて出典の公表値を再現すること（当てはめに使っていない点も含む）
- 濃度帯が隙間なく連続し、境界がすべて公表アンカー値に一致すること
- 全帯が PMID を持つこと、曲線が単調で値域を外れないこと

個体化推定で確認していることは「個体化 MEAC 推定」の節に記載しています（回復テストを含む 29 項目）。

## ファイル構成

```
index.html                     UI
css/main.css                   スタイル（Propofol TCI アプリと共通の語彙、アクセントは teal）
js/models.js                   Patient / DoseEvent / 検証 / セッション形式
js/fentanyl-pk.js              3 つの PK モデル、RK4、tpeak 計算
js/analgesia.js                濃度帯・母集団確率曲線・MAC 減少・呼吸指標
js/individualisation.js        患者ごとの MEAC 事後推定（逐次 Bayes）
js/simulation-engine.js        投与記録の積分、減衰時間、維持速度
js/realtime-engine.js          実時間進行エンジン（×1 / ×10 / ×60）
js/main.js                     コントローラ
validation/validate-pk.js      PK の Evaluator
validation/validate-analgesia.js       鎮痛モジュールの Evaluator
validation/validate-individualisation.js  個体化推定の Evaluator（回復テストを含む）
```

単位系は全体で統一しています: 薬物量 µg、容積 L、濃度 ng/mL (= µg/L)、
クリアランス L/min、時間 min。したがって `A1[µg] / V1[L]` がそのまま ng/mL になります。
